# Abdullah ❤️ Emu — Love Story Website

Static site. Open `index.html` to preview; deploy as-is on GitHub Pages.

## Customize
- **Names, start date, subtitle, music path, gallery, special moments:** `CONFIG` at top of `script.js`
- **Timeline, love letters (Emu / Abdullah):** `index.html` (look for the comments)
- **Colors:** `:root` at top of `style.css`
- **Photos:** put files in `images/` named `photo1.jpg`…`photo10.jpg` (or edit paths + captions in `CONFIG.gallery`). Missing photos show a soft heart placeholder.
- **Music:** put your song at `audio/love-song.mp3`. It plays only when the 🎵 button is tapped.

## Deploy on GitHub Pages
Push all files to a repo → Settings → Pages → Deploy from branch `main` / root. All paths are relative.
